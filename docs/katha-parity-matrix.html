The honest headline: Katha matches or beats SnapReels on the core loop of browse, watch, unlock, pay and earn, and on everything an operator does in admin. The gaps are ads, push, store billing, transactional email, sitemap and a few small screens. None of them is a security or money-path regression, and all of them were planned for phases 2 and later.

Open gaps, prioritised

Everything marked partial or missing, grouped by what it takes to close.

Small, this week if wanted. Web browse and category pages. Sitemap, robots, ads.txt and IndexNow. Force-update screen on mobile. Clear-cache row on mobile. Admin self-service password reset by email. Per-language content visibility enforcement.

Phase 2, needs your accounts. RevenueCat store billing. AdMob rewarded, interstitial and banner with server-side verification, and the admin ads page. Push notifications on all platforms and the admin sender. Phone OTP on mobile through native Firebase. Analytics tag and client beacons. Web Shorts feed. JSON-LD structured data.

Blocks charging money. The media edge verifier. Production will not boot until a signing mode is set, which is deliberate.

Dropped on purpose and not coming back: vendor licence check and install wizard, JSON backup and restore, six storage providers, the static mobile API key, admin-stored secrets, the on-device Gemini service, PayPal and Flutterwave for the first release, Facebook login, the Trending stub, and the performance page that could not save.
